Sections (navigate via side-bar):
  Overview        — national totals, year selector, 5-yr trend, top jurisdictions,
                  3D map preview with real backend data
  India Map       — true 3D extruded choropleth, all 36 jurisdictions selectable,
                  hover tooltip with registered cases, click → dashboard,
                  optional guided camera tour (manual start only)
  State Intelligence — one reusable profile: name, classification, selected-year
                    cases, national ranking, share of national total, previous-year
                    comparison, 2020–2024 trend, comparison with national total,
                    all-jurisdictions mini-table
  National Analytics — 5-yr trend, state vs UT split, top 15 jurisdictions,
                      distribution bands, year-wise comparison charts
  Data Explorer   — search, type filter, sortable table with historical columns,
                  CSV export of exactly the filtered rows
  Methodology     — data provenance, licence (CC BY 2.5 IN), what figures are/not,
                  national vs demo vs original-prototype separation

Key interactions (all from real API, no hardcoded data):
  • Year selector (2020–2024) changes every figure, always matching the backend
  • Hover a state on the 3D map → highlight + name + registered cases + year
  • Click a state → camera flies to it + State Intelligence dashboard opens
  • Tour bar: Start/Pause/Previous/Next/Stop/Reset; never auto-starts
  • CSV export produces the exact filtered rows with correct header
  • Theme toggle (light/dark)
  • Responsive: desktop → tablet → mobile (simplified 3D fallback)

3. FIGURES — what they are and are NOT

Registered cybercrime cases (NCRB, Crime in India, MHA/PIB 21 July 2026)
NOT:
  • confirmed financial fraud transactions
  • individual complaints
  • convictions
  • financial losses
  • recovered amounts
  • population-adjusted rates
  • a measure of underlying crime prevalence (change in registered cases does not
    establish a change in underlying prevalence)

5. REMAINING LIMITATIONS (honest, no hand-waving)

- Reduced-motion CSS rule is applied globally; some skeleton animations use
  CSS keyframes that could be stricter (future polish)
- The 3D map's extruded depth is driven by case counts relative to the highest
  jurisdiction — it is visual/analytical, not to scale
- Island parts are preserved but may appear at a different visual scale than the
  main polygon due to the projection and extrusion
- The guided camera tour follows real geographic centroids; it does not include
  narrative commentary or stop at specific landmarks
- The Data Explorer CSV export includes the filtered rows only; it does not include
  column headers for years beyond the selected year's data range
- WebGL2 is preferred; on systems without hardware acceleration the app degrades
  gracefully via a fallback div (no blank canvas)
